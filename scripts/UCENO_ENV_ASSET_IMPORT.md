# UCENO environment asset import

This marker file starts the dedicated environment-only asset import workflow.
The workflow downloads the selected Poly Haven CC0 models, PBR road/ground
textures and city HDRI into the Unity project. It does not generate an APK.
\nThe selected CC0 model set also includes a sofa, armchair, round table, bed and cabinet for the Unity home furnishing catalogue. The importer stores the downloaded models locally; the game does not fetch assets at runtime.\n
